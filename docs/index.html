Qué es Rukes

Rukes es un launcher de teclado para Windows 10 (22H2) y Windows 11, escrito en Rust. Pulsas Alt+Espacio, escribes y pulsas Enter: abre apps y archivos, calcula, convierte unidades y divisas, cambia el volumen, guarda el historial del portapapeles, inserta snippets, ejecuta tus scripts y workflows, hace peticiones HTTP y admite plugins escritos en cualquier lenguaje.

No envía telemetría ni se conecta a internet salvo lo que actives tú (tasas de cambio, peticiones HTTP que lanzas, scripts o plugins que lo hagan).

Instalación

InstaladorRukes-<versión>-setup-x64.exe. Se instala para tu usuario en %LOCALAPPDATA%\Programs\Rukes, sin permisos de administrador. Al desinstalar se conserva tu configuración.
wingetwinget install HenryOsorio.Rukes
PortableDescomprime Rukes-<versión>-portable-x64.zip donde quieras. Con el archivo portable.txt junto al exe, todo se guarda en la carpeta data de al lado.
Compilarcargo build --release -p rukes-app (Rust estable, toolchain MSVC). El exe queda en target/release/rukes.exe.

Rukes queda residente con un icono en la bandeja. Para que arranque con Windows activa «Iniciar con Windows» en los ajustes (o start_with_windows = true).

Ayuda integrada

help (o info, ayuda) lista todos los comandos. help vol, info calc o help http muestran la ayuda de uno: resumen, ejemplos y consejos. Enter en un ejemplo lo escribe para probarlo y Ctrl+P muestra la ayuda completa. Los plugins externos pueden añadir la suya (ver más abajo).

Ajustes y config.toml

Panel de ajustes

Escribe ajustes, pulsa «Ajustes» en la leyenda o elige «Ajustes…» en el icono de la bandeja. Tiene cuatro pestañas:

  • General: tema (o «según el sistema» con un tema claro y otro oscuro), idioma, atajo, inicio con Windows, terminal.
  • Ventana: posición (centro, arriba o abajo), ancho, resultados visibles, leyenda, qué hacer al abrir, fondo (Mica, Acrílico, sólido), ocultar al perder el foco, animaciones, vista previa.
  • Plugins: activar o desactivar cada uno.
  • Extras: divisas y su descarga, colores, Everything, programas del PATH.

Guardar (o Ctrl+S) escribe solo lo cambiado en config.toml, conserva tus comentarios y se aplica sin reiniciar. Esc vuelve a la búsqueda.

El archivo config.toml

Todo lo demás está en %APPDATA%\Rukes\config.toml, que se crea comentado en el primer arranque. Escribe configuración en Rukes para abrirlo. Se aplica al guardar. Junto a él se genera config.schema.json: con VS Code y la extensión Even Better TOML tienes autocompletado y validación. Si te equivocas, Rukes avisa con la línea y la columna y sigue con la configuración anterior.

[general]
hotkey = "Alt+Space"
language = "auto"            # auto | es | en
theme = "system"             # o un tema: "tokyo-night", "midnight"…
light_theme = "catppuccin-latte"
dark_theme = "tokyo-night"
start_with_windows = false

[window]
position = "center"          # center | top_center | bottom_center
width = 680
max_results = 8
hints = true                 # leyenda de comandos con la búsqueda vacía
backdrop = "auto"            # auto | mica | acrylic | solid

[plugins.calc]
currency_online = false      # descargar tasas de cambio

[plugins.web.engines]        # buscadores: palabra clave = URL con {q}
g = "https://www.google.com/search?q={q}"
gh = "https://github.com/search?q={q}"

Cada plugin tiene su sección [plugins.<nombre>] con al menos enabled.

Apps, perfiles y archivos

Las apps se indexan del menú Inicio, la Tienda y (opcional) el PATH, y se reindexan solas al instalar o quitar programas. Alias propios en [plugins.apps] aliases.

Perfiles

Una app con argumentos fijos, carpeta y alias:

[[plugins.apps.profiles]]
name = "Code en el proyecto"
target = "Visual Studio Code"   # nombre de una app indexada o una ruta
args = "-n C:/proyectos/web"
cwd = "C:/proyectos/web"
alias = ["cw"]
admin = false

Archivos

[plugins.files]
roots = ["~/Desktop", "~/Documents", "~/Downloads"]
exclude = ["**/node_modules", "**/.git"]
min_chars = 3          # caracteres mínimos para buscar archivos sin prefijo
everything = true      # si Everything (voidtools) está abierto, busca en todo el disco

Temas

Incluidos: tokyo-night, catppuccin-latte, catppuccin-frappe, catppuccin-macchiato, catppuccin-mocha, gruvbox, nord, dracula, midnight (negro puro) y rukes-light. Con theme = "system" se usa light_theme o dark_theme según el modo de Windows.

Crear un tema

Crea %APPDATA%\Rukes\themes\mi-tema.toml (nombre en minúsculas, con guiones) y pon theme = "mi-tema". Con extends heredas de otro y cambias solo lo que quieras. Se aplica al guardar.

[theme]
name = "Mi tema"
extends = "tokyo-night"     # opcional
dark = true
backdrop = "mica"           # mica | acrylic | solid (si [window] backdrop = "auto")
opacity = 0.55              # opacidad del fondo sobre Mica/Acrílico
solid_opacity = 1.0         # opacidad con fondo sólido
radius = 8                  # radio de filas e iconos

[theme.colors]
background = "#1a1b26"
foreground = "#c0caf5"
accent = "#7aa2f7"
selection = "#283457"
muted = "#737aa2"
# divider = "#737aa259"         # por defecto, muted con transparencia
# selection_foreground = ""     # por defecto, foreground

[theme.font]
family = "Segoe UI Variable Text"   # cualquier fuente instalada, también Nerd Fonts
size = 15
mono = "Cascadia Mono"

[theme.layout]
row_height = 48
icon_size = 28
search_height = 56
padding = 12
spacing = 12

Los colores admiten #rrggbb y #rrggbbaa. Copia un archivo de la carpeta themes del repositorio como punto de partida.

Idiomas

language = "auto", "es" o "en". Un archivo <código>.toml en la carpeta lang de la configuración cambia textos o añade un idioma (por ejemplo fr.toml); las claves que falten salen en inglés.

[search]
placeholder = "Rechercher…"

Snippets

Textos reutilizables. Escribe su palabra clave (o snip para verlos todos) y pulsa Enter: se pega en la ventana en la que estabas. Se definen en archivos .toml de la carpeta snippets (la primera vez se crea uno de ejemplo) o en archivos .md, uno por snippet.

[[snippet]]
name = "Firma de correo"
keyword = "firma"
content = """
Saludos cordiales,
{campo:Nombre}
"""

[[snippet]]
name = "Fecha de hoy"
keyword = "hoy"
content = "{fecha}"
VariableSe sustituye por
{fecha}, {hora}, {fechahora}Fecha y hora actuales
{portapapeles}Lo que haya en el portapapeles
{cursor}Dónde queda el cursor tras pegar
{campo:Nombre}Un campo que escribes tras la palabra clave: firma Ana (varios separados por ;)
{{ / }}Llaves literales

En un archivo .md la cabecera es opcional:

---
name: Respuesta estándar
keyword: resp
---
Gracias por escribir, {campo:Nombre}. {cursor}

Notas, tareas y recordatorios

  • note idea para el blog añade una nota a notes/notas.md; note lista las recientes.
  • todo comprar pan añade una tarea a notes/tareas.md; todo las lista y Enter completa una.
  • remind 15m llamar a Ana o recordar 14:30 reunión crean un recordatorio con notificación; remind los lista y Ctrl+D cancela.

Los archivos son Markdown normal: sirven también en Obsidian. Las rutas se cambian en [plugins.notes] (notes_file, todo_file).

Portapapeles

clip muestra el historial y clip factura busca en él. Enter pega en la ventana anterior, Ctrl+S fija, Ctrl+D borra. Se guarda cifrado (DPAPI) en tu equipo. No guarda lo que los gestores de contraseñas marcan como sensible ni lo copiado desde las apps de [plugins.clipboard] exclude.

Nada se envía hasta pulsar Enter. La respuesta muestra estado, tiempo y tamaño, y el cuerpo (JSON formateado) en el panel de detalles. Enter sobre el estado repite la petición; sobre el cuerpo, las cabeceras o «Copiar como curl», los copia. El historial solo vive en memoria (puede contener tokens).

Scripts

Cualquier archivo de la carpeta scripts con una cabecera @rukes.name aparece en el launcher sin reiniciar. Sirven PowerShell, Python, JavaScript, .bat, .cmd, ejecutables y Rhai (lenguaje embebido, se ejecuta dentro de Rukes). new script Backup crea uno desde una plantilla, Ctrl+E lo edita y logs muestra el historial de ejecuciones.

# @rukes.name        Saludar
# @rukes.description Escribe «hola Ana» y pulsa Enter
# @rukes.alias       hola
# @rukes.arg         nombre:text:default=mundo
# @rukes.output      notification
# @rukes.timeout     10s

param([string]$nombre = "mundo")
Write-Output "¡Hola, $nombre!"
CabeceraSignificado
name, description, iconCómo aparece en la lista
aliasPalabra clave; lo que escribas después son los argumentos
argnombre:tipo:opciones. Tipos: text, number, file, bool, choice(a|b). Opciones: required, default=…. Llegan en orden y como RUKES_ARG_<NOMBRE>
outputnotification (por defecto), launcher (la salida o resultados JSON en la lista), clipboard, terminal, silent
timeout15s, 2m; 0 sin límite
hotkeyAtajo global, p. ej. Ctrl+Alt+B
admin, cwd, interpreterElevar, carpeta de trabajo, intérprete propio

La cabecera va en comentarios (#, //, REM, ::…) al principio del archivo. Los intérpretes por extensión se configuran en [scripts.interpreters].

Rhai

Funciones disponibles: clipboard, notify, open, run, http, sleep, env, windows, focus_window (y http_get).

// @rukes.name   Mi IP pública
// @rukes.alias  mi ip
// @rukes.output clipboard
let ip = http_get("https://api.ipify.org");
ip.trim();

Workflows y triggers

Un workflow abre apps y webs y las coloca en tus monitores (además de cambiar el tema, el plan de energía, cerrar programas…). Se definen en archivos .toml de la carpeta workflows (la primera vez se crean ejemplos) y aparecen en el launcher por su nombre o alias. Ctrl+P muestra los pasos antes de ejecutarlo.

[workflow.trabajo]
name = "Modo trabajo"
description = "Editor, documentación y terminal"
alias = ["work", "trabajo"]
hotkey = "Ctrl+Alt+1"        # opcional: atajo global
steps = [
  { app = "code", window = { monitor = 1, snap = "left", title = "Visual Studio Code" } },
  { url = "https://docs.rs", window = { monitor = 2, snap = "right" } },
  { app = "wt.exe", window = { monitor = 1, snap = "right" } },
  { wait = "2s" },
  { notify = "Modo trabajo listo" },
]
PasoQué hace
{ app = "…", args, cwd, admin, window }Abre una app
{ url = "…", window }Abre una web
{ script = "nombre", args = "…" }Ejecuta uno de tus scripts
{ wait = "2s" }Espera
{ theme = "nord" }Cambia el tema de Rukes
{ power_plan = "high_performance" }Plan de energía (balanced, power_saver o un GUID)
{ kill = ["Teams.exe"] }Cierra procesos
{ notify = "texto" }Notificación

Ventanas: window = { monitor = 2, snap = "left" }. monitor: 1 es el principal y luego de izquierda a derecha. snap: left, right, top, bottom, cuartos (top-left…), tercios (left-third, center-third, right-third, left-two-thirds…), center, full, maximize. O x, y, width, height en píxeles o "50%". title reconoce la ventana si la app ya estaba abierta.

Triggers

Ejecutan un workflow o un script a una hora, cada cierto tiempo o al iniciar sesión. Se pausan desde la bandeja; triggers lista los próximos.

[[trigger]]
at = "09:00"                 # o every = "30m", o on = "login" / "startup"
days = ["laborables"]        # lun..dom, laborables, finde (opcional)
run = "workflow:trabajo"     # o "script:backup"

Plugins externos

Un plugin es cualquier programa (Python, Node, Rust, Go…) que habla JSON por stdin/stdout, una línea por mensaje. Se instala copiando su carpeta a %APPDATA%\Rukes\plugins\<nombre>; Rukes la vigila, así que se instala y se quita en caliente. plugins muestra su estado. Cada plugin corre en su propio proceso: si se cuelga o muere no afecta al resto (tiempos máximos de 2 s por búsqueda y 10 s por acción; con 3 fallos seguidos queda desactivado).

plugin.toml

[plugin]
name = "Cuenta"
version = "1.0.0"
executable = "python"          # relativo a la carpeta o comando del PATH
args = ["-u", "main.py"]
keywords = ["cuenta", "count"] # "cuenta hola" le envía "hola"
prefix = "%"                   # opcional
global = false                 # true = también en búsquedas sin palabra clave
description = "Cuenta palabras"
icon = "calc"

[permissions]                  # informativos: se muestran al instalar
network = false
clipboard = true

[config]                       # lo recibe en initialize
palabras_por_minuto = 200

Ayuda del plugin

Lo que muestra help cuenta. Sin esta sección se usan la descripción y las palabras clave.

[help]
summary = "Cuenta palabras, caracteres y tiempo de lectura"
tips = ["Enter copia el resultado"]

[[help.usage]]
example = "cuenta hola mundo"
description = "Palabras y caracteres"

Protocolo

Rukes envía initialize, query (con text, el texto sin la palabra clave) y action (al pulsar Enter), y avisa con cancel cuando una búsqueda ya no interesa. El plugin responde con el mismo id.

→ {"id": 2, "method": "query", "params": {"query_id": 17, "text": "hola mundo", "raw": "cuenta hola mundo", "targeted": true}}
← {"id": 2, "result": [{"title": "2 palabras", "subtitle": "Enter copia", "data": "2"}]}
→ {"id": 3, "method": "action", "params": {"item": {"id": "0", "data": "2"}, "action": "open"}}
← {"id": 3, "result": {"copy": "2"}}

Cada resultado admite id, title (obligatorio), subtitle, icon, score, preview, detail, data y actions. La acción puede responder "hide", "keep_open", {"query": …}, {"notify": …}, {"copy": …}, {"open": …} o {"results": [...]}.

Plugin mínimo en Python

import json, sys

for line in sys.stdin:
    msg = json.loads(line)
    if "id" not in msg:
        continue  # cancel
    if msg["method"] == "initialize":
        result = {}
    elif msg["method"] == "query":
        text = msg["params"]["text"]
        result = [{"title": text.upper(), "data": text.upper()}]
    else:  # action
        result = {"copy": msg["params"]["item"]["data"]}
    print(json.dumps({"id": msg["id"], "result": result}), flush=True)

El protocolo completo está en docs/plugin-protocol.md y hay ejemplos en plugins-examples (Python y Rust).

Exportar, importar y portable

  • exportar configuración copia tu configuración (config, temas, scripts, snippets, notas, workflows, plugins) a Documentos\Rukes-config-<fecha>. No incluye la caché ni el historial.
  • importar C:\ruta\Rukes-config-… la restaura; antes guarda una copia de la actual en Rukes-backup-<fecha>.
  • Desde la línea de comandos: rukes.exe --export <carpeta>, --import <carpeta>, --schema <archivo>.
  • Portable: con portable.txt junto a rukes.exe, todo se guarda en la carpeta data de al lado (sirve en un USB).
