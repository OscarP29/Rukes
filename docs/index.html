Qué es Rukes

Un launcher de teclado para Windows 10 (22H2) y Windows 11, escrito en Rust.

Pulsas Alt+Espacio, escribes y pulsas Enter. Desde la misma barra abres apps y archivos, calculas, conviertes unidades y divisas, cambias el volumen o el brillo, recuperas lo que copiaste, insertas snippets, apuntas notas, tareas y recordatorios, lanzas peticiones HTTP, ejecutas tus scripts y workflows y usas plugins escritos en cualquier lenguaje.

RápidoAparece en milisegundos y consume ~20 MB. Cada búsqueda nueva cancela la anterior.
PrivadoSin telemetría. Solo se conecta a internet si tú lo pides (divisas, peticiones HTTP, scripts o plugins que lo hagan).
ConfigurablePanel visual, config.toml con autocompletado, temas, idiomas y atajos propios.
AmpliableScripts en cualquier lenguaje, Rhai embebido, workflows, triggers y plugins por JSON.

Novedades

Fijados, carpetas a un clic y JSON con color

  • Fijados: Ctrl+S fija una app, archivo, carpeta, script o workflow. Al abrir Rukes sin escribir aparecen bajo FIJADOS; Ctrl+1…9 los abre y Alt+↑/↓ los ordena. Ver Fijados.
  • Carpetas de Rukes: carpetas lista las de configuración, workflows, plugins, temas, scripts, snippets, notas y logs; carpeta scripts va directo a una. Ver Carpetas.
  • Respuestas con color en el mini Postman: el JSON se ve con claves, textos, números, true/false/null y signos en colores del tema; las cabeceras, con el nombre resaltado. Ver Mini Postman.

Interfaz más ordenada

  • Leyenda «SUGERENCIAS»: con la búsqueda vacía ves comandos de ejemplo en dos columnas, el comando en monoespaciada y color de acento y una descripción corta. Toda la fila es clicable. Por defecto se ven 6 (configurable).
  • Filas de resultados: icono centrado, título y subtítulo cortados con «…» (las rutas por el medio, para que se vea el nombre del archivo), fondo suave al pasar el ratón. Las tareas muestran «Pendiente · n en total» como etiqueta a la derecha.
  • Separadores de grupo: cuando la lista mezcla resultados de varios tipos aparecen líneas finas con el nombre del grupo (APLICACIONES, ARCHIVOS, TAREAS…).
  • Pie de atajos: bajo la lista, a la izquierda la acción de Enter de la fila seleccionada y a la derecha hasta dos atajos que tengan sentido para ella.
  • Encabezado: «Nuevo» y «Ajustes» son iconos a la derecha de la búsqueda, con su nombre al pasar el ratón.
  • Ajustes en tarjetas: navegación lateral con barra de acento, ajustes agrupados (Apariencia, Sistema, Tamaño, Leyenda de comandos, Comportamiento), casillas de la leyenda en una columna con contador «n de m elegidos».
  • Temas base nuevos: «Rukes Oscuro» (rukes-dark) y «Rukes Claro» (rukes-light), predeterminados para el modo oscuro y claro, y tokens de tema nuevos.

Mini Postman visual

Un panel de teclado para probar APIs: método, URL y Enviar en una barra, pestañas Headers, Body, Auth y Params con Tab, historial con las flechas y pegado de órdenes curl. Ver Mini Postman.

Crear desde el launcher y comandos entre plugins

nuevo crea temas, workflows, scripts y plugins; Ctrl+D borra notas; y los scripts Rhai pueden crear notas, tareas y recordatorios (comandos entre plugins).

Instalación

FormaCómo
InstaladorRukes-<versión>-setup-x64.exe. Se instala para tu usuario en %LOCALAPPDATA%\Programs\Rukes, sin permisos de administrador. Al desinstalar se conserva tu configuración.
PortableDescomprime Rukes-<versión>-portable-x64.zip donde quieras. Con el archivo portable.txt junto al exe, todo se guarda en la carpeta data de al lado.
CompilarRust estable con el toolchain MSVC:
cargo build --release -p rukes-app
# el ejecutable queda en target\release\rukes.exe

Rukes queda residente con un icono en la bandeja (mostrar, ajustes, editar config.toml, recargar, pausar triggers, salir). Para que arranque con Windows activa «Iniciar con Windows» en los ajustes o pon start_with_windows = true.

La ventana

La ventana tiene siempre la misma estructura; solo cambia lo que hay bajo la búsqueda.

┌──────────────────────────────────────────────────────────┐ │ Buscar… │ ＋ ⚙ │ ← encabezado ├──────────────────────────────────────────────────────────┤ │ APLICACIONES ───────────────────────────────────────── │ ← separador de grupo │ [icono] Visual Studio Code [⧉][📁][ⓘ] │ ← fila seleccionada │ C:\…\Microsoft VS Code\Code.exe │ │ ARCHIVOS ───────────────────────────────────────────── │ │ [icono] informe-final.docx │ │ C:\Users\ana\Docu…\informe-final.docx │ ├──────────────────────────────────────────────────────────┤ │ [↵] Abrir [Ctrl+↵] Administrador │ ← pie de atajos └──────────────────────────────────────────────────────────┘

Búsqueda y encabezado

El campo de búsqueda ocupa siempre el mismo sitio: arriba en el centro, arriba o abajo según [window] position. A su derecha, separados por una línea fina, están los iconos Nuevo (＋, escribe new ) y Ajustes (⚙, abre el panel). Al pasar el ratón muestran su nombre.

Leyenda de comandos

Con la búsqueda vacía aparece la etiqueta SUGERENCIAS y una lista de comandos de ejemplo: a la izquierda el comando y a la derecha qué hace. Un clic lo escribe en la búsqueda. Debajo, un recordatorio de las teclas principales. En los ajustes (Ventana → Leyenda de comandos) eliges cuántos se ven y cuáles; en config.toml:

[window]
hints = true          # false quita la leyenda
hints_count = 6       # cuántos ejemplos se ven
# Cuáles y en qué orden (vacío = los de siempre). Ids: calc, files, web, clip, todo,
# remind, new, help, shell, snip, note, controls, windows, wall, workflows, http.
hints_items = ["calc", "files", "web", "todo", "http", "new"]

Filas de resultados

Todas las filas tienen la misma anatomía: icono de tamaño fijo a la izquierda; título y subtítulo en el centro (cortados con «…»; las rutas se cortan por el medio); y a la derecha los botones de las demás acciones (copiar, abrir la carpeta, como administrador, ver detalles…), que solo aparecen en la fila seleccionada o bajo el ratón. Las tareas llevan su estado como etiqueta a la derecha.

Fijados

Para tener a mano lo que más abres: selecciona una app, un archivo, una carpeta (también las de carpetas), un script o un workflow y pulsa Ctrl+S (o el botón 📌 de la fila). La próxima vez que abras Rukes sin escribir nada verás tus fijados en lugar de la leyenda de comandos:

┌──────────────────────────────────────────────────────────┐ │ Buscar… │ ＋ ⚙ │ ├──────────────────────────────────────────────────────────┤ │ FIJADOS ────────────────────────────────────────────── │ │ [icono] Visual Studio Code ← Ctrl+1 │ │ [icono] Carpeta de scripts ← Ctrl+2 │ │ [icono] informe-final.docx ← Ctrl+3 │ ├──────────────────────────────────────────────────────────┤ │ [↵] Abrir [Ctrl+1…9] Abrir [Alt+↑↓] Mover │ └──────────────────────────────────────────────────────────┘
TeclaQué hace
Ctrl+SFija el resultado; sobre uno fijado, lo quita
Ctrl+1 … Ctrl+9Abre el fijado N (escribiendo, el resultado N de la lista)
Alt+↑ / Alt+↓Sube o baja el fijado seleccionado

Caben hasta 30 y se guardan en %LOCALAPPDATA%\Rukes\state\pinned.json. Si desinstalas una app fijada, al abrirla verás un error: quítala con Ctrl+S. En el portapapeles Ctrl+S sigue fijando el elemento dentro del historial.

Pie de atajos

Con resultados en la lista, el pie muestra a la izquierda la acción de Enter de la fila seleccionada (por ejemplo ↵ Abrir, ↵ Copiar, ↵ Completar) y a la derecha como mucho dos atajos que apliquen a esa fila:

Se muestraCuándo
Ctrl+↵ AdministradorLa fila se puede abrir como administrador (apps, ejecutables).
Ctrl+P Vista previaLa fila tiene un archivo que previsualizar.
Ctrl+P DetallesLa fila tiene un texto de detalle (ayuda, respuesta de un plugin…).

Vista previa

Ctrl+P (o el botón ⓘ de una fila) abre a la derecha un panel con la imagen, los datos del archivo, el texto o el Markdown del elemento. Se abre solo con [window] preview_panel = true.

Anclada abajo

Con position = "bottom_center" la barra queda junto a la barra de tareas y los resultados crecen hacia arriba, con el mejor pegado a la búsqueda. Por eso ↑ va a los siguientes y ↓ vuelve.

Rukes aprende: lo que eliges más a menudo para una búsqueda sube en la lista (frecency).

Ayuda integrada

help (o info, ayuda) lista todos los comandos. help vol, info calc o help http muestran la ayuda de uno: resumen, ejemplos y consejos. Enter en un ejemplo lo escribe para probarlo y Ctrl+P muestra la ayuda completa. Tus plugins pueden añadir la suya (sección [help]).

Crear desde el launcher

Escribe nuevo (o new, crear, o pulsa el icono ＋) y elige qué crear. Rukes pregunta lo que falte, escribe el archivo en su carpeta y lo abre en tu editor.

EscribeCrea
nuevo tema Mi temathemes\mi-tema.toml, heredando del tema actual (o del que elijas) con todos sus valores comentados. Se activa al momento.
nuevo workflow Modo focoworkflows\modo-foco.toml con un workflow de ejemplo y un trigger comentado.
nuevo script BackupUn script en el lenguaje que elijas (PowerShell, Python, JavaScript, Rhai, .bat…) con su cabecera.
nuevo plugin Mi botplugins\mi-bot\ con plugin.toml y un programa que ya responde al protocolo, en Python, Node.js o PowerShell.

Panel de ajustes

Escribe ajustes, pulsa el icono ⚙ o elige «Ajustes…» en la bandeja. A la izquierda, las pestañas; la activa lleva una barra de acento. A la derecha, los ajustes agrupados en tarjetas: cada fila tiene el nombre y una descripción corta a la izquierda y el control (interruptor, lista, deslizador con su valor, texto) a la derecha.

PestañaTarjetas y ajustes
GeneralApariencia: tema (o «según el sistema»), tema oscuro y claro, idioma. Sistema: atajo, iniciar con Windows, terminal.
VentanaTamaño: posición, ancho, resultados visibles. Leyenda de comandos: mostrarla, cuántos, cuáles (con contador «n de m elegidos»). Comportamiento: qué hacer al abrir, fondo (Mica, Acrílico, sólido), ocultar al perder el foco o tras una acción, animaciones, vista previa.
PluginsActivar o desactivar cada plugin y el atajo del mini Postman.
ExtrasDivisas y su descarga, colores, Everything, programas del PATH.

Guardar (o Ctrl+S) escribe solo lo cambiado en config.toml, conserva tus comentarios y se aplica sin reiniciar; está desactivado mientras no cambies nada. Cancelar o Esc vuelve a la búsqueda. «Editar config.toml» abre el archivo.

config.toml

Todo lo demás está en %APPDATA%\Rukes\config.toml, que se crea comentado en el primer arranque (escribe configuración para abrirlo). Se aplica al guardar. Junto a él se genera config.schema.json: con VS Code y la extensión Even Better TOML tienes autocompletado, descripciones y validación. Si te equivocas, Rukes avisa con la línea y la columna y sigue con la configuración anterior.

[general]
hotkey = "Alt+Space"
language = "auto"            # auto | es | en
theme = "system"             # o un tema: "rukes-dark", "nord", "midnight"…
light_theme = "rukes-light"
dark_theme = "rukes-dark"
start_with_windows = false
terminal = "wt"

[window]
position = "center"          # center | top_center | bottom_center
width = 680
max_results = 8
hints = true                 # leyenda de comandos con la búsqueda vacía
hints_count = 6
backdrop = "auto"            # auto | mica | acrylic | solid
on_show = "select_all"       # select_all | keep | clear
hide_on_blur = true
animations = true
preview_panel = false

[plugins.calc]
currency_online = false      # descargar tasas de cambio

[plugins.http]
enabled = true
hotkey = ""                  # p. ej. "Ctrl+Alt+P" abre el mini Postman

[plugins.web.engines]        # buscadores: palabra clave = URL con {q}
g = "https://www.google.com/search?q={q}"
gh = "https://github.com/search?q={q}"

Cada plugin tiene su sección [plugins.<nombre>] con al menos enabled y, en muchos, priority (−1..1, se suma a la puntuación).

Apps, perfiles y archivos

Las apps se indexan del menú Inicio, la Tienda y (opcional) el PATH, y se reindexan solas al instalar o quitar programas. Alias propios en [plugins.apps] aliases.

Perfiles

Una app con argumentos fijos, carpeta y alias:

[[plugins.apps.profiles]]
name = "Code en el proyecto"
target = "Visual Studio Code"   # nombre de una app indexada o una ruta
args = "-n C:/proyectos/web"
cwd = "C:/proyectos/web"
alias = ["cw"]
admin = false

Archivos

[plugins.files]
roots = ["~/Desktop", "~/Documents", "~/Downloads"]
exclude = ["**/node_modules", "**/.git"]
min_chars = 3          # caracteres mínimos para buscar archivos sin prefijo
everything = true      # si Everything (voidtools) está abierto, busca en todo el disco

Temas y tokens

Incluidos: rukes-dark y rukes-light (los temas base), tokyo-night, catppuccin-latte, catppuccin-frappe, catppuccin-macchiato, catppuccin-mocha, gruvbox, nord, dracula y midnight (negro puro, sin transparencia). Con theme = "system" se usa light_theme o dark_theme según el modo de Windows (por defecto, rukes-light y rukes-dark).

Tokens de color

Ningún componente usa colores fijos: todos leen estos tokens del tema. Si un tema no define alguno, Rukes lo calcula a partir de los demás para no romperlo.

Un token fijado en el tema toma la opacidad del fondo (para no tapar Mica o Acrílico). Si un tema hereda de otro (extends) y cambia el fondo o el texto sin fijar surface, esta se vuelve a calcular en vez de heredar la del tema base, que no casaría.

Crear un tema

Lo más rápido: nuevo tema Mi tema. A mano: crea %APPDATA%\Rukes\themes\mi-tema.toml (minúsculas, con guiones) y pon theme = "mi-tema". Con extends heredas de otro y cambias solo lo que quieras. Se aplica al guardar.

[theme]
name = "Mi tema"
extends = "rukes-dark"      # opcional
dark = true
backdrop = "mica"           # mica | acrylic | solid (si [window] backdrop = "auto")
opacity = 0.55              # opacidad del fondo sobre Mica/Acrílico
solid_opacity = 1.0         # opacidad con fondo sólido
radius = 8                  # radio de filas, iconos y botones

[theme.colors]
bg = "#0f1115"
surface = "#171a21"
surface_hover = "#1f2430"
border = "#262b36"
text = "#e6e9ef"
text_muted = "#9aa3b2"
text_faint = "#6b7385"
accent = "#7aa2f7"
accent_soft = "#7aa2f726"   # #rrggbbaa: el último par es la opacidad
selection = "#1f2a40"

[theme.font]
family = "Segoe UI Variable Text"   # cualquier fuente instalada, también Nerd Fonts
size = 15                           # el resto de tamaños escala a partir de este
mono = "Cascadia Mono"              # solo para comandos y código

[theme.layout]
row_height = 48
icon_size = 28
search_height = 56
padding = 12
spacing = 12

Con size = 15: títulos de fila 15 px, descripciones 13 px, rutas y pie 12 px y búsqueda 20 px. En contraste alto de Windows Rukes usa los colores del sistema.

Idiomas

language = "auto", "es" o "en". Un archivo <código>.toml en la carpeta lang de la configuración cambia textos o añade un idioma (por ejemplo fr.toml); las claves que falten salen en inglés.

Snippets

Textos reutilizables. Escribe su palabra clave (o snip para verlos todos) y pulsa Enter: se pega en la ventana en la que estabas. Se definen en archivos .toml de la carpeta snippets o en archivos .md, uno por snippet.

[[snippet]]
name = "Firma de correo"
keyword = "firma"
content = """
Saludos cordiales,
{campo:Nombre}
"""

[[snippet]]
name = "Fecha de hoy"
keyword = "hoy"
content = "{fecha}"

{portapapeles}Lo que haya en el portapapeles
{cursor}Dónde queda el cursor tras pegar
{campo:Nombre}Un campo que escribes tras la palabra clave: firma Ana (varios separados por ;)
{{ / }}Llaves literales

Portapapeles

clip muestra el historial y clip factura busca en él. Enter pega en la ventana anterior, Ctrl+S fija, Ctrl+D borra. Se guarda cifrado (DPAPI) en tu equipo. No guarda lo que los gestores de contraseñas marcan como sensible ni lo copiado desde las apps de [plugins.clipboard] exclude.

Mini Postman (HTTP)

Desde la búsqueda:

Nada se envía hasta pulsar Enter, que abre el panel:

┌──────────────────────────────────────────────────────────────┐ │ [ POST ▾ ] https://api.ejemplo.com/login [Enviar ↵] │ ├──────────────────────────────────────────────────────────────┤ │ Headers (1) Body • Auth Params JSON, formulario… │ ← Tab │ { │ │ "user": "ana" │ │ } │ ├──────────────────────────────────────────────────────────────┤ │ [200 OK] 84 ms 1,2 KB application/json ⌃⇧C Copiar · ⌃H · Esc │ │ { │ │ "token": "eyJhbGci…" │ │ } │ ├──────────────────────────────────────────────────────────────┤ │ Ctrl+Enter reenvía · Tab pestañas · Ctrl+H cabeceras · … │ └──────────────────────────────────────────────────────────────┘
  • Pegar un curl en la barra (también los de «Copiar como cURL» del navegador, estilo bash o cmd, con \ o ^ al final de línea) rellena método, URL, cabeceras y cuerpo. Entiende -X, -H, -d y variantes, --data-urlencode, --json, -u, -G, -I, -A, -b, -e y --url; ignora las opciones que no afectan a la petición.
  • Headers: una por línea, Nombre: valor (las líneas con # se ignoran). Params: uno por línea, clave=valor; se codifican y se añaden a la URL. Auth: Bearer <token>, Basic usuario:clave, usuario:clave (Basic) o un token suelto (Bearer).
  • Body: si es JSON válido y no pones Content-Type, se envía como application/json; si parece un formulario, como application/x-www-form-urlencoded. Con cuerpo y método GET, se usa POST.
  • Respuesta: estado en color (2xx correcto, 3xx acento, 4xx aviso, 5xx error), tiempo, tamaño y tipo; debajo el cuerpo con JSON sangrado, que se puede seleccionar. Se muestran hasta 512 KB.
  • Colores: si el Content-Type es JSON o el cuerpo empieza por { o [, las claves van en el color de acento, los textos en verde, los números en ámbar, true/false/null en rojo y los signos en gris. Con Ctrl+H las cabeceras resaltan su nombre. HTML y texto se muestran sin color. Los tonos salen del tema activo.

Los atajos están en Atajos de teclado. El historial solo vive en memoria (puede contener tokens) y se borra al cerrar Rukes.

Scripts

Cualquier archivo de la carpeta scripts con una cabecera @rukes.name aparece en el launcher sin reiniciar. Sirven PowerShell (.ps1), Python (.py), JavaScript (.js, .mjs) y TypeScript (.ts, con Deno o Bun), .bat/.cmd, ejecutables y Rhai (.rhai, se ejecuta dentro de Rukes, sin instalar nada). new script Backup crea uno desde una plantilla, Ctrl+E lo edita y logs muestra el historial de ejecuciones (con la salida y los errores).

La cabecera

Va en comentarios al principio del archivo (#, //, --, ;, ::, REM, ' o dentro de <# … #> / /* … */).

# @rukes.name        Crear issue en GitHub
# @rukes.description Abre un issue nuevo en el repo actual
# @rukes.alias       gh issue
# @rukes.arg         title:text:required
# @rukes.output      notification
# @rukes.timeout     15s
# @rukes.hotkey      Ctrl+Alt+I

param([string]$title)
gh issue create --title "$title" --body "Creado desde Rukes"
Write-Output "Issue «$title» creado"
CabeceraSignificado
name (title)Nombre en la lista. Obligatorio.
description (desc)Subtítulo.
iconRuta de un icono.
alias (keyword)Palabra clave (puede tener varias palabras: gh issue). Lo que escribas después son los argumentos. Varios separados por comas.
argnombre:tipo:opciones, uno por línea. Tipos: text, number, file, bool, choice(a|b|c). Opciones: required, default=….

Argumentos

Cada argumento toma una palabra (o un texto entre comillas), salvo el último si es de tipo texto, que se queda con el resto de la línea: con @rukes.arg title:text:required, gh issue Mi bug grave pasa Mi bug grave como título. Llegan en orden como argumentos del programa y también como variables de entorno RUKES_ARG_<NOMBRE>.

Resultados en la lista (script filters)

Con @rukes.output launcher, si el script escribe JSON con una lista (o un objeto con items), cada elemento es una fila:

# @rukes.name   Proyectos
# @rukes.alias  proy
# @rukes.output launcher
import json, os, sys

query = os.environ.get("RUKES_QUERY", "").lower()
base = os.path.expanduser("~/proyectos")
items = [
    {"title": d, "subtitle": os.path.join(base, d), "open": os.path.join(base, d)}
    for d in sorted(os.listdir(base)) if query in d.lower()
]
print(json.dumps({"items": items}))

subtitle (description)Segunda línea.
iconRuta de un icono.
open (url, path)Abre la ruta, URL o URI.

Por extensión: .py → python, py o python3; .js → node, deno run o bun run; .ts → deno run o bun run; .ps1 → PowerShell; .bat/.cmd → cmd. Se usa el primero que esté en el PATH. Para otros:

Rhai

Rhai es un lenguaje de scripts pequeño, parecido a Rust y a JavaScript, que va dentro de Rukes: no hay que instalar nada y arranca al instante. Rukes no lo inventó; lo integra con una API propia y segura.

Lo esencial del lenguaje

// Variables y constantes
let nombre = "Ana";
const LIMITE = 10;

// Texto con interpolación (comillas invertidas)
let saludo = `Hola, ${nombre}`;

// Listas y mapas (los mapas empiezan con #{ )
let lista = [1, 2, 3];
let persona = #{ nombre: "Ana", edad: 31 };
persona.ciudad = "Madrid";

// Condiciones y bucles
if lista.len() > 2 { print("larga"); } else { print("corta"); }
for n in lista { print(n * 2); }
let i = 0;
while i < 3 { i += 1; }

// switch con varios valores por rama
let tipo = switch persona.edad {
    0..18 => "menor",
    18..65 => "adulto",
    _ => "senior",
};

// Funciones (no ven las variables de fuera: pásalas como parámetros)
fn doble(x) { x * 2 }
print(doble(21));

// Errores
try {
    throw "algo falló";
} catch (e) {
    print(`capturado: ${e}`);
}

// El último valor es el resultado del script
saludo
Detalles que despistan: las funciones no capturan variables de fuera; try/catch es una instrucción, no una expresión (asigna dentro); y métodos como trim() modifican la cadena en su sitio y no devuelven nada.

Qué recibe el script

NombreContenido
queryLo escrito tras el alias
argsMapa con los argumentos de la cabecera: args.nombre
selected_fileArchivo seleccionado en el Explorador (o vacío)
active_windowTítulo de la ventana que tenía el foco

Qué devuelve

  • Lo escrito con print y el valor final (si es texto o un número) son la salida: va a la notificación, al portapapeles o a la lista según @rukes.output.
  • Si el valor final es una lista de mapas con title, cada uno es una fila (mismos campos que los script filters).
  • throw "texto" termina con error: se notifica y queda en logs.

Límites de seguridad

  • No puede leer ni escribir archivos ni importar módulos; eval está desactivado.
  • Respeta el @rukes.timeout y se puede cancelar desde logs: el motor lo comprueba mientras avanza y también dentro de sleep, run y http.
  • Máximos: 64 niveles de llamada, textos de 16 MB, listas de 1 000 000 elementos, mapas de 100 000 claves; cada petición HTTP hasta 30 s y 8 MB; solo URLs http(s).

Workflows

Un workflow abre apps y webs y las coloca en tus monitores (además de cambiar el tema, el plan de energía, cerrar programas…). Se definen en archivos .toml de la carpeta workflows (la primera vez se crean ejemplos; nuevo workflow crea otro) y aparecen en el launcher por su nombre o alias. Ctrl+P muestra los pasos antes de ejecutarlo; workflows los lista.

Triggers

Un trigger ejecuta un workflow o un script solo: a una hora, cada cierto tiempo, al arrancar Rukes o al iniciar sesión. Van en los mismos archivos de workflows. triggers lista los próximos con su hora; se pausan todos desde la bandeja («Pausar triggers»).

# A una hora, ciertos días
[[trigger]]
name = "Arranque del día"        # opcional: nombre en la lista
at = "09:00"
days = ["laborables"]            # opcional; sin days, todos los días
run = "workflow:trabajo"

# Cada cierto tiempo (mínimo 1 minuto)
[[trigger]]
every = "1m"
run = "script:telegram"

# Al iniciar sesión en Windows (si Rukes arranca con Windows)
[[trigger]]
on = "login"
run = "script:backup"

# Al arrancar Rukes
[[trigger]]
on = "startup"
run = "limpiar-descargas"        # sin prefijo: workflow si existe, si no script
enabled = false                  # desactivado sin borrarlo
CampoValores
atHora "HH:MM" (formato 24 h)
everyIntervalo: "30m", "2h", "1h30m" (mínimo 1 minuto)
on"startup" (inicio, arranque) o "login" (sesión)
dayslun, mar, mie, jue, vie, sab, dom (o en inglés: mon…, monday…), laborables / weekdays, finde / weekend
run"workflow:id", "script:nombre" o un nombre suelto
enabledfalse lo desactiva

Cada trigger lleva exactamente uno de at, every u on. Si el equipo estaba apagado o suspendido a la hora de un at, esa ejecución se salta (no se ejecuta tarde). login solo se dispara si Rukes arranca poco después de iniciar sesión. Si un trigger falla, la notificación lo dice y queda en logs.

Plugins externos

Un plugin es cualquier programa (Python, Node, PowerShell, Rust, Go, C#…) que habla JSON por stdin/stdout, una línea por mensaje. Cada plugin corre en su propio proceso: si se cuelga o muere, el launcher sigue funcionando.

Crear uno en 1 minuto

  1. Escribe nuevo plugin Mayúsculas y elige el lenguaje (Python, Node.js o PowerShell).
  2. Rukes crea %APPDATA%\Rukes\plugins\mayusculas\ con plugin.toml y un programa que ya funciona, y lo abre en el editor.
  3. Escribe la palabra clave (por defecto, el nombre en minúsculas) y un texto: ya responde.
  4. Edita el programa y guarda: Rukes lo recarga solo.

Cómo funciona

Rukes tu plugin (proceso aparte) ───── ────────────────────────── 1.ª vez que se usa: arranca el proceso ───▶ initialize {config, locale} ───▶ lee su configuración ◀─── {"result": {}} usuario escribe «may hola» query {text: "hola", query_id: 17} ───▶ calcula resultados ◀─── {"result": [{"title": "HOLA", "data": "HOLA"}]} sigue escribiendo «may hola m» cancel {query_id: 17} ───▶ (puede dejar de trabajar) query {text: "hola m", query_id: 18} ───▶ … pulsa Enter action {item: {id, data}, action: open} ───▶ hace lo que toque ◀─── {"result": {"copy": "HOLA M"}} Rukes se cierra: cierra stdin ───▶ el plugin termina

La carpeta de plugins se vigila: copiar o borrar una carpeta, o guardar su plugin.toml, recarga los plugins sin reiniciar. Al instalar uno nuevo, una notificación muestra su nombre, versión y permisos. plugins lista los instalados, su estado, permisos y los errores del manifiesto.

plugin.toml

[plugin]
name = "Cuenta"                # nombre visible (obligatorio)

  • Hace falta al menos keywords, prefix o global = true.
  • Un campo desconocido en [plugin] es un error (para detectar erratas).
  • El id del plugin es ext:<carpeta>.
  • Glifos para icon: calc, web, shell, folder, script, note, todo, clipboard, http, generator, help, plugin, ok, error… o swatch:#rrggbb para una muestra de color.
  • La carpeta de plugins se cambia con [plugins.external] dir; enabled = false desactiva todos los externos.

Protocolo

Ciclo de vida

  • El proceso se arranca la primera vez que se usa, con la carpeta del plugin como directorio de trabajo, sin ventana, y con RUKES_PROTOCOL=1, PYTHONUNBUFFERED=1 y PYTHONIOENCODING=utf-8.
  • Lo primero que recibe es initialize.
  • stderr va al log de Rukes: úsalo para depurar.
  • Debe terminar cuando se cierra stdin (Rukes se cierra o recarga los plugins). Si muere, se vuelve a arrancar en la siguiente consulta.
LlamadaTiempo máximo
initialize5 s
query2 s
action10 s

Agotar el tiempo, morir o no poder arrancar es un fallo; con 3 fallos seguidos el plugin queda desactivado hasta que se recargue (guardar su plugin.toml) o lo reinicies desde plugins (Enter). Un error devuelto por el plugin no cuenta como fallo. Mientras espera a un plugin, Rukes sigue mostrando los resultados de los demás.

Mensajes

→ {"id": 1, "method": "initialize", "params": {"protocol": 1, "config": {"palabras_por_minuto": 200}, "locale": "es", "plugin_dir": "C:\\…\\plugins\\cuenta"}}

→ Rukes al plugin, ← plugin a Rukes. Los mensajes con id esperan respuesta con el mismo id; los que no lo tienen son notificaciones. results entrega resultados parciales de una búsqueda lenta antes de la respuesta final.

query

  • text: lo escrito sin la palabra clave ni el prefijo.
  • raw: lo que escribió el usuario.
  • targeted: true si se usó la palabra clave o el prefijo; false en búsquedas globales (solo con global = true; entonces text nunca está vacío).

Plugins de ejemplo

Python (mínimo)

import json, sys

for line in sys.stdin:
    msg = json.loads(line)
    if "id" not in msg:
        continue  # cancel: no se responde
    if msg["method"] == "initialize":
        result = {}
    elif msg["method"] == "query":
        text = msg["params"]["text"]
        result = [{"title": text.upper(), "data": text.upper()}]
    else:  # action
        result = {"copy": msg["params"]["item"]["data"]}
    print(json.dumps({"id": msg["id"], "result": result}), flush=True)

Python con submenú y varias acciones

import json, sys, urllib.parse

def send(msg):
    sys.stdout.write(json.dumps(msg, ensure_ascii=False) + "\n")
    sys.stdout.flush()

def query(p):
    text = p["text"].strip()
    if not text:
        return [{"title": "Escribe una palabra para buscarla", "actions": []}]
    q = urllib.parse.quote(text)
    return [{
        "id": "buscar",
        "title": f"Buscar «{text}»",
        "subtitle": "Enter elige dónde · botones: copiar",
        "icon": "web",
        "data": {"text": text, "q": q},
        "actions": ["open", {"id": "copiar", "label": "Copiar el texto"}],
    }]

def action(p):
    data, act = p["item"]["data"], p["action"]
    if act == "copiar":
        return {"copy": data["text"]}
    if act == "wiki":
        return {"open": f"https://es.wikipedia.org/wiki/{data['q']}"}
    if act == "rae":
        return {"open": f"https://dle.rae.es/{data['q']}"}
    # Enter en el primer resultado: un submenú
    return {"results": [
        {"title": "Wikipedia", "data": data, "actions": [{"id": "wiki", "label": "Abrir"}]},
        {"title": "Diccionario RAE", "data": data, "actions": [{"id": "rae", "label": "Abrir"}]},
    ]}

for line in sys.stdin:
    msg = json.loads(line)
    if "id" not in msg:
        continue
    try:
        m = msg["method"]
        result = {} if m == "initialize" else query(msg["params"]) if m == "query" else action(msg["params"])
        send({"id": msg["id"], "result": result})
    except Exception as e:
        sys.stderr.write(f"error: {e}\n")            # al log de Rukes
        send({"id": msg["id"], "error": {"message": str(e)}})

Node.js

const readline = require("readline");

let config = {};
const send = (msg) => process.stdout.write(JSON.stringify(msg) + "\n");

function query(params) {
  const text = params.text;
  if (!text) return [{ title: "Escribe algo", actions: [] }];
  return [{ id: "mayus", title: text.toUpperCase(), subtitle: "Enter copia", data: text.toUpperCase() }];
}

function action(params) {
  return { copy: params.item.data };
}

const rl = readline.createInterface({ input: process.stdin });
rl.on("line", (line) => {
  const msg = JSON.parse(line);
  if (msg.id === undefined) return; // cancel
  try {
    let result;
    if (msg.method === "initialize") { config = msg.params.config || {}; result = {}; }
    else if (msg.method === "query") result = query(msg.params);
    else result = action(msg.params);
    send({ id: msg.id, result });
  } catch (e) {
    send({ id: msg.id, error: { message: String(e) } });
  }
});
rl.on("close", () => process.exit(0));

Comandos entre plugins

Algunos plugins ofrecen comandos sin interfaz para que otros (y los scripts Rhai) los usen. Así un bot puede crear notas o recordatorios.

PluginComandoArgumentos → resultado
notesadd{text} → {text, file}
noteslist{limit: 10} → ["texto", …]
notesdelete{text} → true si existía
todoadd{text} → {text, file}
todolist→ [{line, text}, …]
todocomplete{text} → true si existía
remindadd{when: "15m"}, {seconds} o {at} (Unix) y {text} → {id, due, text}
remindlist→ [{id, due, text}, …]
remindcancel{id} → true si existía
// Desde Rhai
let r = plugin_call("remind", "add", #{ when: "15m", text: "sacar el té" });
let pendientes = plugin_call("todo", "list");
for t in pendientes { print(t.text); }
plugin_call("todo", "complete", #{ text: "comprar pan" });

// Qué hay disponible
for c in plugin_commands() { print(`${c.plugin}.${c.command}: ${c.description}`); }
Los plugins externos aún no pueden llamar a estos comandos (el protocolo v1 solo va de Rukes al plugin). Mientras tanto, un plugin externo puede escribir directamente en los Markdown de notas y tareas, o delegar en un script Rhai.

Depurar un plugin

  • Escribe en stderr (o envía {"method": "log"}): aparece en %LOCALAPPDATA%\Rukes\logs. Con RUKES_LOG=debug verás también cada mensaje.
  • plugins muestra el estado (activo, desactivado por fallos, error de manifiesto) y Enter lo reinicia.
  • Prueba el programa a mano: pégale las líneas del protocolo por la consola.
  • Escribe siempre una línea por mensaje y haz flush tras cada una (en Python, flush=True o -u).
  • Usa UTF-8 en la entrada y la salida (la plantilla de PowerShell ya lo configura).
cd %APPDATA%\Rukes\plugins\cuenta
python -u main.py

Exportar, importar y portable

  • exportar configuración copia tu configuración (config, temas, scripts, snippets, notas, workflows, plugins) a Documentos\Rukes-config-<fecha>. No incluye la caché ni el historial.
  • importar C:\ruta\Rukes-config-… la restaura; antes guarda una copia de la actual en Rukes-backup-<fecha>.
  • Portable: con portable.txt junto a rukes.exe, todo se guarda en la carpeta data de al lado (sirve en un USB).
rukes.exe --export D:\copias\rukes
rukes.exe --import D:\copias\rukes
